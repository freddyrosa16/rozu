# Rozu dried rose

Selected September 9, 2026. An asymmetric dried rose with curled, angular petals and custom lowercase lettering.

- `rose-light.svg`: lightweight vector implementation for dark backgrounds.
- `wordmark-light.svg`: custom lowercase lettering used in the website header.
- `logo-light.svg` and `logo-graphite.svg`: combined rose and wordmark used in the GitHub README for dark and light themes.
- `../../../favicon.svg`: ivory rose on a graphite rounded square.

The website pairs the SVG rose with the custom SVG wordmark. The lettering is outlined artwork, not a font dependency. All assets are lightweight SVG implementations of the selected design.
